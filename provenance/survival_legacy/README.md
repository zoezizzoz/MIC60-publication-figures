# Historical survival reference — not a certified current panel source

Recovered from the existing repository's pre-deletion history (parent commit `24d26907e9455b9e9ac2bf6a60e5e6670814d1ad`). Original CSV and R script are preserved without alteration. The R script treats nonmissing times as deaths, drops blanks and applies IQR filtering. Its working directory expects the CSV beside the script. Do not run it as the current analysis without first reconciling missing-time/censoring rules and its match to Fig3G.
