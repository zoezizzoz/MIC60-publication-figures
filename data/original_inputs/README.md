# Original graph-analysis inputs

These are recoverable measurement workbooks, DAM monitor records, count matrices, differential-expression tables and pathway inputs associated with the plotted graphs. Historical panel folder names are retained. Instrument images, Leica LIF files and sequencing reads were excluded at the author's request. Some source folders contain duplicates because multiple graphs used the same input; Git stores identical file contents once.

`Original_Data` is the source package's historical label. Count matrices, normalized counts, DE and enrichment tables are processed analysis inputs, not raw sequencing reads. Use `../../plotted_data/INDEX.csv` for the current panel-to-data map.
