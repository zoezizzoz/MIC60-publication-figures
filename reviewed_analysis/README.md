# Reviewed analysis and restored inputs

This directory preserves the reviewed workflow from the existing repository and restores its recoverable graph inputs. Use the repository-level [plotted-data index](../plotted_data/README.md) to find data using current panel letters. The [reproduction guide](../REPRODUCING.md) distinguishes frozen plotting values, fresh statistical fits and newer panel generators.

`run_all.py` executes nine analysis stages with logs and optional controlled publication output. Do not use `--publish` to replace manually refined figures unless that is intended. The original stage details are retained in WORKFLOW.md; statements there describing a code-only snapshot refer to the September 18 baseline.
