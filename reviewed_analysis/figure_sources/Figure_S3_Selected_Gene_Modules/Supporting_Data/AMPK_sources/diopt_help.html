Using the text box option:
Gene and/or protein identifiers should be entered one per line. Different types of identifiers can be entered together.

Example (fly genes): 

        Nmd3
        lace
        FBgn0000339
        FBgn0032679
        CG5110
        CG5861
        par-1
        wg

Using the file upload option:
Please upload a text file with one gene/protein per line.
