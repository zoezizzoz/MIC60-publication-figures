DIOPT API

Python Users there is an un-official community created wrapper available on PyDIOPT (pypi / gitgub.)

End Points 

        https://www.flyrnai.org/tools/diopt/web/diopt_api/{api version}/get_orthologs_from_entrez/{input Species}/{entrez Gene ID}/{target Species}/{filter}

Parameters

Species

Where Species is the NCBI Taxonomy ID Supported IDs Include:

  • all   All Species (Avaiable for Target only)
  • 83333 Escherichia coli [ E. coli ]
  • 3702 Arabidopsis thaliana [ Thale cress ]
  • 4896 Schizosaccharomyces pombe [ Fission yeast ]
  • 4932 Saccharomyces cerevisiae [ Yeast ]
  • 6239 Caenorhabditis elegans [ Worm ]
  • 7165 Anopheles gambiae [ Mosquito ]
  • 7227 Drosophila melanogaster [ Fly ]
  • 7955 Danio rerio [ Zebrafish ]
  • 8364 Xenopus tropicalis [ Western clawed frog ]
  • 10116 Rattus norvegicus [ Rat ]
  • 10090 Mus musculus [ Mouse ]
  • 9606 Homo sapiens [ Human ]
  • 6945 Ixodes scapularis [ Black-legged tick ]

Filter

Filtering based on scores.

  • none No Filter, Show All results
  • best_match Return only best match when there is more than one match per input gene or protein
  • exclude_score_less_1 Exclude low diopt scores (score > 1, unless only match score is 1)
  • exclude_score_less_2 Exclude low diopt scores (score > 2, unless only match score is 1 or 2)

API Versions

DIOPT Dataset Version

  • v9 or v10
